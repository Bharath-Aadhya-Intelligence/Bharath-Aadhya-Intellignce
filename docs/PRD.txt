SECTION 1
Product Vision & Goals

1.1  Executive Summary
This document defines the complete product, design, and engineering requirements for the official corporate introduction website of Bharath Aadhya Intelligence (BAI) — an India-based IT services organisation.
The website is BAI's primary digital front-door. It must communicate organisational credibility, articulate the breadth of IT service capabilities, build trust with decision-makers, and convert qualified visitors into business conversations. The design and structural approach is inspired by the HackCulture.io aesthetic — dark, modern, enterprise-grade, and conversion-optimised — adapted entirely for an IT services context.
Core Mission: Bharath Aadhya Intelligence exists to empower India's digital future. The website must communicate this mission instantly, confidently, and memorably to every visitor.

1.2  Strategic Objectives
	•	Establish BAI as a credible, premium IT services brand for Indian enterprises, SMBs, startups, and government institutions.
	•	Generate qualified inbound leads — primarily 'Get In Touch' form submissions and direct contact initiations.
	•	Communicate BAI's six core IT service capabilities clearly and with tangible business outcomes.
	•	Build immediate trust through impact statistics, client testimonials, and partner/client logos.
	•	Achieve top-tier performance: sub-2s load time, mobile-first, accessibility compliant.
	•	Support organic discoverability through on-page SEO optimised for high-intent IT services keywords in India.
	•	Serve as the foundation for future digital growth — blog, case studies, careers, and client portal.

4.3  'Get In Touch' / Contact Interaction Specification
This is the primary conversion action for the website. Every element of the contact flow must be optimised for completion rate and lead quality.

Option A — Calendly Embed (Recommended)
	•	On 'Book a Discovery Call' click: Open full-screen modal overlay. Load Calendly inline widget.
	•	Event type: 30-minute 'Discovery Call'. Automated reminders at 24h and 1h prior.
	•	UTM parameters passed through to Calendly as custom fields for source attribution.
	•	Post-booking: Thank-you page with confirmation + 'Download Capabilities Deck' CTA.
	•	CRM: Calendly webhook → Zapier → HubSpot creates Contact + Deal record automatically.
Option B — Inline Contact Form (Fallback)
5-field form, inline on page at the #contact anchor:
	•	Full Name (text, required)
	•	Business Email (email, required — corporate domain preferred)
	•	Organisation Name (text, required)
	•	Service of Interest (dropdown: 6 services, required)
	•	Brief description of requirement (textarea, optional, max 500 chars)
	•	Submit: POST to CRM API. Show inline success state — no redirect. SDR notified via Slack + email instantly.

SECTION 6
Non-Functional Requirements

6.1  Performance Requirements
Core Web Vitals Targets
• LCP (Largest Contentful Paint): < 2.5s
• INP (Interaction to Next Paint): < 100ms
• CLS (Cumulative Layout Shift): < 0.1
• FCP (First Contentful Paint): < 1.2s
• TTFB (Time to First Byte): < 600ms
Optimisation Methods Required
• Images: WebP/AVIF with lazy loading + width/height attrs
• Fonts: preconnect hints + font-display: swap
• JS: code-split bundles, defer non-critical scripts
• CDN: Vercel Edge or Cloudflare for static assets
• SSG: All pages statically generated (Next.js ISR)

6.3  SEO Requirements
	•	Every page has a unique <title> (50–60 chars) and <meta description> (150–160 chars).
	•	Structured data (JSON-LD): Organisation, WebSite, LocalBusiness schemas.
	•	Open Graph + Twitter Card meta tags on all pages.
	•	Canonical URLs on all pages.
	•	XML sitemap auto-generated and submitted to Google Search Console.
	•	Priority target keywords: 'IT services company India', 'digital transformation services India', 'cloud services India', 'AI solutions India', 'custom software development India', 'cybersecurity services India'.
6.4  Accessibility — WCAG 2.1 AA
	•	All images: descriptive alt attributes.
	•	All interactive elements: keyboard-navigable. Visible focus indicators.
	•	Colour contrast: minimum 4.5:1 for body text, 3:1 for large text and UI components.
	•	Carousels/marquees: pause control, ARIA roles and live region announcements.
	•	Forms: <label> elements associated, error messages programmatically linked.
	•	Semantic HTML: <header>, <nav>, <main>, <section>, <footer>, correct heading hierarchy.
	•	Animated elements: honour prefers-reduced-motion media query.
6.5  Security & Compliance
	•	HTTPS enforced. Force redirect from HTTP to HTTPS.
	•	Content Security Policy (CSP) headers to prevent XSS.
	•	GDPR / India DPDP Act 2023: Cookie consent banner required before analytics/ad pixels fire.
	•	Form rate limiting to prevent spam submissions.
	•	No sensitive data stored client-side.
	•	All environment variables server-side only; never exposed in client bundle.
