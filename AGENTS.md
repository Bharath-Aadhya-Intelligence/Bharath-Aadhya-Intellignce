# Design & Layout Rules (Strict Quality Standards)

## FORBIDDEN DESIGN PATTERNS (NEVER USE):
1. **No Tacky Sci-Fi / Crypto / AI-Slop Aesthetics:**
   - **Colors:** NEVER use glowing electric neon palettes (e.g., `#00F2FE` cyan, `#8B5CF6` electric purple, `#4953F5` bright indigo gradients).
   - **Gimmicks:** NEVER add fake terminal windows with fake macOS buttons, fake telemetry counters, fake latency badges (`<18ms TTFT`), or fake progress bars (`94.8% compression efficiency`).
   - **Overlays:** NEVER plaster background tech grids, radial glow blobs, or sci-fi matrix effects across the layout.

2. **No HackCulture / Generic Hackathon Copy-Pastes:**
   - NEVER use `Syne` font with all-caps bold-italic slogans ("BUILDING INDIA'S *AI FUTURE*").
   - NEVER use the HackCulture structure: giant centered purple gradient hero, 3x2 repetitive service boxes, giant single-color rounded cards, or hackathon boilerplate ("Programs", "Challenges", "Community", "Live in 15m").
   - NEVER fabricate buzzword-heavy copy (e.g., claiming MoE 8x7B, air-gapped appliances, etc.) when the company is an engineering/IT agency.

## REQUIRED DESIGN STANDARDS:
1. **Restraint, Craft & Quiet Confidence:**
   - Use clean, modern, and credible layouts inspired by world-class software studios and tech leaders (e.g., Stripe, Linear, Apple, Vercel, Metalab).
   - Generous whitespace, refined micro-typography, crisp contrast, and subtle 1px neutral borders.
   - Clean, professional color schemes: refined off-whites, neutral slates, deep charcoal, or minimal monochromes with subtle, purposeful accents.
2. **Authentic, Grounded Presentation:**
   - Real, credible descriptions of actual software capabilities (web engineering, mobile development, custom AI integration, product incubation).
   - True craftsmanship: balanced spacing, real-world hierarchy, and professional polish.
